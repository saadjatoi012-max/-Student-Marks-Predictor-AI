# Student Marks Predictor using AI

Ye project predict karta hai ke student kitne ghante parhne se kitne marks le sakta hai.

## Tools Used
- Python
- Pandas - Data handling
- Scikit-learn - Linear Regression Model  
- Matplotlib - Data Visualization

## How to Run
1. Install: `pip install pandas matplotlib scikit-learn`
2. Run: `python ai_project.py`

## Output
Agar student 7.5 ghante parhega to expected marks: 72.50
